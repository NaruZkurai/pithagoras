# Built-in skills

Loaded from here for every session, without being installed. They belong to the
portal, so the Skills tab shows them read-only — the way to change one is to
change it here.

`skill-creator` teaches the agent to write skills: the format, the frontmatter
and its failure modes, supporting files, and where to put one so it loads. It is
also an example of what it describes, which is the point — a skill with a
reference directory, written the way it says to write them.

To add one, make a directory containing a `SKILL.md`. It is picked up on the
next restart.
